# Contributing to Tech Unfiltered AGI

First off, thank you for considering contributing to Tech Unfiltered AGI! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## 🛠️ How to Contribute

### 1. Reporting Bugs
If you find a bug in the Next.js frontend or the AGI Docker stack, please open an issue! 
Be sure to include:
- Your operating system and Docker version.
- Steps to reproduce the bug.
- Expected behavior vs actual behavior.

### 2. Suggesting Enhancements
Have an idea for a new AI agent? Want to add a new dashboard metric?
- Open a "Feature Request" issue.
- Describe the feature in detail and why it would be valuable to the ecosystem.

### 3. Pull Requests
1. **Fork** the repository and clone it locally.
2. **Branch** off of `main` (`git checkout -b feature/your-feature-name`).
3. **Commit** your changes clearly (`git commit -m "feat: Add new transcription agent"`).
4. **Push** to your fork and submit a Pull Request.

## 💻 Local Development
If you are contributing code:
- **Frontend changes**: Run `npm run dev` in the `tech-unfiltered/` directory. Ensure your code passes all linting rules (`npm run lint`).
- **Backend changes**: If you are modifying the Python agents, you can build the Docker containers locally using `docker compose up --build`.

Thank you for helping us build the future of autonomous media!
